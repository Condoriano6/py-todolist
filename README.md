#Python Todo

A simple Todo List application built with Python.

## Features

- Add tasks
- Remove tasks
- Edit task
- Mark tasks as completed
- Mark tasks as incomplete
- Show tasks and sort them based on:
  1. Priority
  2. Title
  3. ID
  4. Status (Done/Undone)
- Give statistics
- Save files
- Load files

## Technologies

- Python 3

## Libraries

- colorama
- json
