# Python Todo

A simple Todo List application built with Python.

## Features

- Add tasks
- Remove tasks
- Edit tasks
- Mark tasks as completed
- Mark tasks as incomplete
- Show tasks:
    - sort them based on:
        1. Priority
        2. Title
        3. ID
        4. Status (Done/Undone)
    - filter them based on:
        1. High priority
        2. Medium priority
        3. Low priority
        4. Done
        5. Undone
- Give statistics
- Save files
- Load files

## Technologies

- Python 3

## Libraries

- colorama
- json
